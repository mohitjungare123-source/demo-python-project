# Demo Python Project

A simple demonstration Python project with basic structure and examples.

## Project Structure

```
demo_python_project/
├── README.md
├── requirements.txt
├── setup.py
├── demo_app/
│   ├── __init__.py
│   ├── main.py
│   └── utils.py
└── tests/
    ├── __init__.py
    └── test_utils.py
```

## Installation

1. Create a virtual environment:
   ```bash
   python -m venv venv
   source venv/bin/activate  # On Windows: venv\Scripts\activate
   ```

2. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Running the Project

```bash
python -m demo_app.main
```

## Running Tests

```bash
pytest
```

## Features

- Basic module structure
- Utility functions with examples
- Unit tests
- Requirements management
